**線上遊玩：[空中之島](https://shuoen88.github.io/sky-island/)** · GitHub 原始碼：[shuoen88/sky-island](https://github.com/shuoen88/sky-island)

直接雙擊此資料夾的 **index.html**，使用電腦版 Chrome 或 Edge 開啟。按「開始探索」即可進入；滑鼠鎖定失敗也會以免鎖定模式遊玩。內建瀏覽器可直接按「不鎖定滑鼠遊玩」。Esc 可暫停並釋放滑鼠。所有執行資源均附在資料夾內，不需安裝、伺服器或網路。

## 「開始探索」沒有反應的修正

先重新整理目前遊戲頁面，按 **不鎖定滑鼠遊玩（內建瀏覽器）**。此按鈕完全不呼叫滑鼠鎖定權限：WASD 移動、空白鍵跳躍、方向鍵轉視角，或按住右鍵拖曳轉視角。右鍵輕點才會放方塊，拖曳不會誤放。E 工坊返回會保留免鎖定模式。

一般「開始探索」也不再等權限成功才啟動；鎖定被拒絕、API 不存在或請求一直無回應時，都可先移動與用方向鍵操作。支援鎖定的瀏覽器仍可使用原本的直接滑鼠轉向。

若顯示「無法啟動 3D」或 Codex 內建頁面無法載入本機檔案，可到 Windows 遊戲資料夾雙擊 **LaunchGame.cmd**，它會以已安裝的 Edge／Chrome 開啟 index.html，沒有啟動伺服器或更改瀏覽器設定。此啟動檔由使用者手動執行，本次沒有代為開啟或測試外部瀏覽器。換瀏覽器不會自動搬移存檔，原資料仍保留在原瀏覽器。

所有本機腳本加上版本參數，避免 HTML 與舊快取腳本混用。載入失敗、缺少模組或執行錯誤會顯示訊息及重新載入按鈕，不再留下沒有說明的開始畫面；這些修正不會清除建築存檔。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| WASD / 滑鼠或方向鍵 | 移動 / 轉向，可與跳躍、Shift 同時使用 |
| 空白鍵 | 在地面起跳，不能二段跳 |
| 長按左右任一 Shift | 移動時衝刺，消耗體力 |
| 長按滑鼠左鍵 | 挖準星指向的方塊，距離上限 5 格 |
| 靠近掉落物 | 自動拾取，單種背包上限 999 |
| 1–8 | 選擇快捷格材料 |
| E | 開啟／關閉工坊，分解、合成、配置快捷格 |
| 滑鼠右鍵 | 鎖定模式直接放置；免鎖定模式輕點放置、按住拖曳轉向 |
| R | 回到目前檢查點，恢復體力 |
| Esc | 暫停、開啟選單 |

草地與泥土需挖 0.7 秒，石頭 2 秒。鬆開左鍵或換目標會清除裂痕，進度從頭開始。方塊被挖掉後會拋出小方塊、落地旋轉；需走近才能拾取。背包為零或放置位置與角色重疊時，不能放置。

## 24 關跑酷與體力

新增 24 關、共 324 段跳躍，每關 8–19 個落點。Esc 開選單可自由選關，亦可照關卡順序挑戰。四個主題為薄荷草原、莓果雲境、蜜桃高地、星空稜線；材質改成 64×64 卡通方塊，使用色塊、粗邊框、高光、草皮波浪邊與三階卡通光照，全部由程式產生，無需外部素材包。

難度依序增加落點數量、單格與雙格比例、橫向偏移、間隙及連續爬升。落點包含單格、橫雙格、直雙格、L、反 L、田字、T、十字、窄長條、折線及廣場等 12 種足跡。每關最高點由 6 格逐漸提升到 9 格；單次上升最多 1 格，大下落最多 4 格，符合角色跳躍能力。

**只有薄荷色、標示 CHECKPOINT 且有圓環的平台保存重生位置**。每關只有 1–2 個檢查點，前期約每 4 個落點一次、中期每 6 個、後期每 8 個。普通落點只更新進度，死亡或 R 會回最近檢查點，並需重走後續落點；尚未碰到檢查點則回本島。HUD 的 ◆ 表示檢查點。

**依序踩到終點會立即回本島，保存成績並準備下一關**，不用自行按 R。第 24 關完成後留在第 24 關，可以再挑戰或從選單選其他關。本島的挖掘／放置修改及背包在關卡切換時保留；所有未拾取掉落物會清除，請先拾取。換關會重建本島裝飾與跑道，不保留跑道上的自行放置方塊。刷新會重建基礎世界，隨後自動套用已儲存的本島改動與背包。

步行每秒 3.6 格，衝刺每秒 7.5 格。體力上限 100，每秒衝刺消耗 25，約可持續 4 秒。停止衝刺 0.8 秒後，每秒恢復 22。耗盡後需放開 Shift 並恢復至少 35 才能再衝刺，原地按住 Shift 不扣體力。

沿跑道前進，在邊緣按 W + Shift + 空白鍵。落點有側向與高度變化，請用滑鼠對準。窄台上可在空中或落地前放開方向鍵煞停，站穩休息，再移向下一段的起跳邊。所有平台足跡相連，L／折線台須沿方塊走，不能直接穿越缺角。

全部 324 段跳躍都以正式物理測試通過，24 關亦完成模擬控制器流程驗證。測試允許每次落地後停止恢復體力，不代表可全程按住 Shift 不休息通關，也不等於真人操作或實際畫面已實測。

衝刺有全畫面速度線、手臂擺動、鏡頭起伏與視角拉寬，選單可減少效果並尊重系統偏好。全螢幕需瀏覽器允許，視窗模式也會覆蓋整個遊戲畫面。

目前關卡及各關最佳時間儲存在 localStorage。舊五平台版本的成績原鍵保留，避免與新版不同路線混用。本島方塊改動、背包與快捷格也會自動保存；關內檢查點、當次計時與未拾取物不保存。禁止儲存時仍可玩，但刷新後會失去建築與背包變更，介面會提示儲存失敗。

## 中央奇幻大廳、採集與建築

本島為 55×44 格。已移除原本右側的雙塔教堂，改為中央奇幻公會大廳；主廳中心約在 x=3.5、z=19.5，位於本島中間。初次開啟會朝向新大廳，北側仍是跑酷入口，西側樹林、資源堆與自由建築區保留。

設計參考使用者提供的 [GraySun Enchanting Tower 影片](https://www.tiktok.com/@graysunbuilds/video/7474273895349013766)，已在瀏覽器看過建造過程與尖頂完成畫面。採用白色塔身、深木構、外挑屋簷與層疊尖頂的視覺元素，重新設計為本島的中央建築群，沒有複製原作的世界檔或建築原始碼。

- 中央藍瓦主廳：挑高中庭、凹入窗面、突出柱墩、前門廊、陽台與吊燈，前後門皆可走通。
- 27 格高紫紅尖塔：切角塔身、木構腰線、外挑陽台、逐層收尖的屋頂與銅飾檐口。
- 西側低銅頂側翼：暖色木石結構，與主廳有連通門。
- 右側木構工坊：獨立尖屋頂、凹入門廊與不同於主廳的窗牆配置。
- 後方露臺與棚架：可由主廳後側門走到露臺入口；上方橫樑與立柱形成開放空間。

窗框、斜撐、托架、欄杆和吊燈以細比例立體構件批次繪製，增加不同厚度、陰影面與前後層次。這些是保護建築的視覺裝飾，不可單獨採集，也不作為角色碰撞或跑酷落點；主要樓板、牆體與屋頂仍是實體方塊。大廳與必要跑道受保護，自己搭建請使用西側空地。

舊版自建與採集紀錄、背包及成績保留。若自建方塊與新建築重疊，會優先保留自建方塊及既有移除紀錄，並在選單顯示保留數量；你可自行拆回重疊方塊調整。出生淨空區與原跑道仍維持保護，存檔不會為了換大廳而清空。

WASD、Shift、空白鍵與滑鼠採獨立輸入狀態，可以在跳躍時轉向。如果筆電按鍵時觸控板暫停回報滑鼠事件，也可用 **方向鍵左右轉身、上下看**，並同時按 WASD 和空白鍵。鎖定滑鼠時焦點交給遊戲畫布，避免停留在按鈕。無法在本環境確認使用者觸控板的硬體／系統抑制是否為原問題原因。

樹幹與樹葉是可碰撞、可挖掘方塊。準星指向樹幹長按左鍵約 1.1 秒，樹葉約 0.3 秒，靠近拾取。採集是逐格挖掘，不會砍一格就讓整棵樹倒下或自動生長。必要時可搭木板向上採集。

按 **E** 進工坊時世界暫停。用 1–8 選擇要配置的快捷格，點材料即可裝入該格，按 E 返回後右鍵放置。配方有 ×1、×4 兩種批次，材料不足停用；輸出超過 999 時整批取消且不扣料。玻璃略透明，燈磚本身發亮，並不投射動態光影。

18 種可用材料：草地、泥土、石頭、原木、樹葉、木板、木樑、石磚、白石、砂岩、玻璃、彩繪玻璃、藍瓦、金飾磚、燈磚、紫紅瓦、銅飾磚、粗石基。初始提供木板 32、石磚 48、白石 24、玻璃 16、藍瓦 24、燈磚 8，讓你立刻試蓋。其餘可從採集與配方取得。

這些是遊戲配方，無需另建熔爐或工作台。所有建築材料目前都是完整一格方塊，沒有半磚、斜坡或門的開關機構。島內建築高度可到 39 格，出生點上方保留淨空，不能用方塊堵住。自己建的方塊可挖回材料。

本島改動、樹木採集、背包及快捷格在變更後約 0.6 秒自動存於目前瀏覽器。刷新同一個遊戲檔案時還原，換瀏覽器／裝置不會同步；未拾取掉落物不保存。「重建本島與本關」會先詢問再清除建築／採集與背包，關卡最佳紀錄保留。原五平台及 24 關成績鍵未刪除。

世界方塊改用 InstancedMesh 依材質合批，降低擴大本島後的繪圖呼叫；實際幀率仍須在你的電腦確認。

## 檔案與驗證

- `index.html` / `style.css`：遊戲介面。
- `boot.js`：顯示載入／啟動錯誤與重新載入按鈕。
- `LaunchGame.cmd`：使用者手動在 Windows 開啟 Edge／Chrome 的入口，不用改動安全設定。
- `test-start.js`：鎖定成功／拒絕／缺失／無回應／錯誤事件、免鎖定操作與載入錯誤的回歸測試。
- `app.js`：Three.js 場景、挖掘掉落拾取放置、控制與視覺動畫。
- `core.js`：物理、碰撞、世界結構、體力及放置限制。
- `courses.js`：24 關布局、12 種足跡、配色、檢查點與通關規則。
- `home.js`：中央大廳建築群、細部構件、森林與資源堆。
- `sandbox.js`：材料、配方、庫存驗證與存檔還原。
- `input.js`：按鍵、跳躍緩衝、滑鼠與方向鍵視角。
- `test-sandbox.js`：10 項輸入／本島／配方／存檔測試，執行 `node test-sandbox.js`。
- `test-core.js`：12 項核心測試，包含全部 324 段跳躍。執行 `node test-core.js`。
- `test-home.js`：7 條正式物理步行參觀路線，執行 `node test-home.js`。
- `test-runtime.js`：Node 以 DOM／繪圖替身測試正式 app.js 的採集、合成、放置、保存重啟與 24 關控制器流程，執行 `node test-runtime.js`。不需安裝套件；不代表瀏覽器或畫面驗證。
- `verify.md`：已檢查、待實測及環境限制。
- `BRIEF.md` / `PLANS.md`：依實際需求整理的範圍與實作紀錄，為 AI 撰寫，非使用者先行提交的作業紀錄。

3D 畫面需 WebGL。本次環境無法做本機瀏覽器驗收，因此未保證特定電腦的幀率、滑鼠鎖定權限與全螢幕行為。舊電腦可先以較小視窗操作。
